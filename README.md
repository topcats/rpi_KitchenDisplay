# rpi_KitchenDisplay

Raspberry PI touchscreen / IO buttons web based display screen. One touch installation script

## Base Installation

Initial Installation and process setup

```bash
sudo apt-get install git sed -y
git clone https://github.com/topcats/rpi_KitchenDisplay.git KitchenDisplay
sudo chmod +x KitchenDisplay/systemsetup.sh
```

## General Setup

Main system setup

```bash
cd ~/KitchenDisplay
sudo ./systemsetup.sh
```
